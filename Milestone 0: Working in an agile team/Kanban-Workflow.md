# Reflection

## How does Kanban help manage priorities and avoid overload?
Kanban helps manage priorities by making all current work visible and showing the stage each task is in. Tasks can be organised into columns such as Not Started, In Progress, Ready for Review, and Approved by Bot, which makes it easier to see what should be worked on next and what is waiting for feedback or approval. Kanban also helps prevent overload by limiting how many tasks are being worked on at the same time. For example, instead of starting several issues at once, I can focus on completing a smaller number of tasks before moving on to new ones. 

## How can you improve your workflow using Kanban principles?
I can improve my workflow by keeping the status of each issue up to date and only moving a task into In Progress when I am actively working on it. I can also prioritise completing existing work before starting additional tasks.
