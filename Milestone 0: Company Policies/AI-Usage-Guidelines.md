# Reflection

## When should you use AI for assistance, and when should you rely on your own skills?
AI is most useful when I am having minor difficulties with a task and need quick help understanding an unfamiliar concept. It is also useful when I want suggestions for debugging an issue or want another way of approaching a problem. I should still rely on my own skills to understand the task, make decisions about the implementation and review the final result. I should not use AI to complete work without understanding what the generated code is doing.


## How can you avoid over-reliance on AI while still benefiting from it?
I can avoid over-reliance by attempting to understand and solve a problem myself before immediately asking AI for the answer. When I do use AI, I can use it as a learning and support tool rather than automatically accepting the solution it gives me. I will also make sure I can explain any code that I submit and understand why the solution works.

## What steps will you take to ensure data privacy when using AI tools?
Before entering anything into an AI tool, I will check that it does not contain confidential Focus Bear information, proprietary code, user data, credentials, API keys or authentication tokens. Furthemore, If I need help with a problem involving sensitive code, I will remove identifying information and create a simplified or generic example that demonstrates the same problem without exposing Focus Bear information.

# Task

## Identify one task you can improve using an AI tool, and try it out.
One task I can improve using AI is identifying possible test cases and edge cases when developing frontend components. For this task, I used ChatGPT to suggest possible test cases for my university project's React CRUD homepage. It suggested testing situations such as empty inputs, invalid inputs, successful submissions, failed submissions and repeated button clicks.

## Review the AI-generated output critically—did it require editing or fact-checking?
The AI generated suggestions were useful for identifying situations I may not have immediately considered, but they were still general suggestions. I would need to review the actual component requirements and determine which test cases are relevant before implementing them. I would also verify any generated code against official documentation and run the tests myself rather than assuming that the AI generated solution works correctly.

## Document one best practice you will follow when using AI tools at Focus Bear.
One best practice I will follow is to never copy and paste proprietary Focus Bear code or confidential information into an AI service. If I need AI assistance, I will describe the problem using a simplified example and review the response critically before applying it to my work.
